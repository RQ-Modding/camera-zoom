# Camera zoom — agent notes

This file is optional. It is read only because this mod is installed.

This mod has no buttons and no `rq.agent.control` ids. It only widens the cleared-dungeon camera range (lock 35, cleared 17.5–120). If this file is missing, do not invent zoom controls for it.

The slider on the dungeon HUD is the vanilla camera scrollbar, not this mod. Do not press it as part of a camera-zoom test unless the walk asked for the vanilla slider.
